한국소방자재총판 홈페이지 - 1차 시안

구성: index.html (단일 파일, 반응형)
기능: 9개 카테고리, 28개 예시 상품, 검색/필터, 견적함, 수량 변경, 견적 요청서 복사, 이메일 초안 열기

중요:
- 참고 사이트의 카테고리만 참고하여 재구성했습니다. 상품 사진·가격·본문은 복제하지 않았습니다.
- 상품은 대표 예시이며 정확한 모델명, 규격, 인증, 가격, 재고를 확인 후 업데이트해야 합니다.
- 실제 서버 전송이나 관리자 DB는 아직 연결되지 않았습니다. 이메일 수신 주소도 미설정입니다.
- 회사 주소, 사업자번호, 전화번호, 이메일은 확인 전이므로 비워두었습니다.
- 힐코프 GitHub 저장소에 업로드하지 마세요. 새 저장소를 만들어 index.html만 업로드하세요.

배포: 별도 GitHub 저장소 생성 → index.html 업로드 → Netlify에서 해당 저장소 연결.
